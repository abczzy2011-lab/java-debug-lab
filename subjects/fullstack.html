LEARNING ORDER · 学习顺序

建议学习顺序

不要按“看起来高级”的顺序学。先打通数据、网络和后端服务，再进入前端与 API 契约，最后用测试、部署和项目实战把能力锁住。

STEP 01数据库 + 网络 + 后端框架

先能独立写 API、连数据库、看懂请求链路。

STEP 02前端框架 + API / 认证

把真实接口接进 React / Vue，完成登录和权限。

STEP 03测试 + DevOps

让核心链路可回归，让 push 能自动上线。

STEP 04安全性能 + 毕业项目

做一次审计、压测和完整项目交付。
